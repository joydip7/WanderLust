# WanderLust ⛪

 **Live Demo:** https://wanderlust-o2hu.onrender.com  

WanderLust is a full-stack web application inspired by Airbnb that allows users to explore, create, and manage property listings with image uploads and secure authentication.

---

## 🚀 Features

- Create, edit, and delete property listings  
- Upload images using Cloudinary  
- User authentication (Signup/Login/Logout)  
- Add and manage reviews  
- Only listing owners can modify their listings  
- Persistent login sessions  
- Responsive and clean UI  

---

## 🛠️ Tech Stack

- **Frontend:** EJS, Bootstrap, CSS  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB Atlas  
- **Authentication:** Passport.js  
- **Image Storage:** Cloudinary  
- **Deployment:** Render  

---

## 🔒 Security

- Environment variables for sensitive data  
- Session-based authentication  
- Input validation using Joi  

---

## 💡 About

This project demonstrates a complete full-stack workflow including backend development, authentication, database integration, cloud storage, and deployment. It is designed to simulate a real-world rental platform with scalable architecture and clean code practices.
